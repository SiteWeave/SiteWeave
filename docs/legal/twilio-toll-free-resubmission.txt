SiteWeave sends transactional SMS to construction project assignees about assigned project work (task reminders, assignment notices, project links). We do not send promotional or blast marketing SMS.

CONSENT IS REQUIRED BEFORE ANY SUBSTANTIVE MESSAGE
Substantive SMS is blocked in our application until the recipient's phone number has status "confirmed" in our sms_phone_consent database table. No task reminders or project alerts are sent until consent is recorded.

PRIMARY OPT-IN — WEB FORM (point of consent collection)
1. A project administrator adds the assignee's mobile number in SiteWeave and taps "Get SMS consent link." The administrator attests: "I confirm this person is on my project and expects operational texts at this number."
2. SiteWeave generates a unique, time-limited link: https://www.siteweave.org/sms-consent/{token}
3. The administrator shares the link or QR code with the assignee on site (no app install required).
4. On their mobile browser, the assignee sees a dedicated SMS consent page with:
   - Organization name and program description (transactional project SMS, not marketing)
   - Message types (task reminders, assignment notices, project links)
   - Message frequency (as needed; typically low volume)
   - "Msg & data rates may apply"
   - "Reply HELP for program info. Reply STOP to opt out"
   - Clickable Terms of Service: https://www.siteweave.org/legal/terms-of-service
   - Clickable Privacy Policy: https://www.siteweave.org/legal/privacy-policy
   - The assignee's masked phone number (read-only, pre-filled for that link)
   - A required unchecked checkbox the user must actively select: "I agree to receive project-related SMS from {Organization} via SiteWeave."
   - A submit button: "Confirm SMS consent"
5. The assignee checks the box and submits. Consent is stored (sms_phone_consent, consent_method=web_form, status=confirmed). Only then may SiteWeave send substantive project SMS to that number.

ALTERNATE OPT-IN — REPLY YES (secondary path only)
If web consent is not used, a project administrator may tap "SMS OK?" to send ONE automated opt-in text. The recipient must reply YES (optionally with a 6-character code) before any substantive SMS. Until YES is received, our system blocks all substantive messages to that number.

OPT-IN MESSAGE (alternate text path — first outbound only)
"{Organization} via (SiteWeave): Welcome! Reply YES {code} to confirm receiving project task SMS alerts. Msg&data rates may apply. HELP/STOP anytime. Terms/Privacy: www.siteweave.org/legal"

CONFIRMATION MESSAGE (after web submit or YES reply)
"You're confirmed for SiteWeave project SMS. You'll receive task and project messages as needed. Msg&data rates may apply. Reply STOP to opt out."
