OPT-IN WORKFLOW DESCRIPTION (long form)
================================================================================
SiteWeave provides transactional SMS for construction project teams. We do not send promotional blast campaigns.

PRIMARY — WEB CONSENT (recommended)
1. A project administrator adds the assignee's mobile number in SiteWeave and taps "Get SMS consent link."
2. The administrator shares the link or QR code with the assignee on site (no SiteWeave app required).
3. The assignee opens https://www.siteweave.org/sms-consent/{token} on their phone browser.
4. The page shows: organization name, program description, message types, frequency, Msg&data rates, HELP/STOP instructions, links to Terms and Privacy, the assignee's masked phone number (read-only), and a required checkbox: "I agree to receive project-related SMS from {Org} via SiteWeave."
5. The assignee submits the form. Consent is stored before any substantive SMS is sent.

ALTERNATE — REPLY YES
1. A project administrator taps "SMS OK?" on a task or triggers an opt-in text.
2. SiteWeave sends one automated opt-in text from [YOUR_TOLL_FREE_NUMBER].
3. The recipient replies YES (optionally with a 6-character verification code) to confirm.
4. Until YES is received, no substantive project SMS is sent.

OPT-OUT: Recipient texts STOP, STOPALL, or UNSUBSCRIBE. We record opt-out globally and confirm unsubscribe.
HELP: Recipient texts HELP for program instructions and policy links.

================================================================================
OPT-IN KEYWORDS (inbound — recipient texts TO us)
================================================================================
YES          — confirm SMS opt-in (may include 6-character code: YES ABC123)
Y            — confirm SMS opt-in (short form)
STOP         — opt out of all SiteWeave SMS to this number
STOPALL      — opt out (alias)
UNSUBSCRIBE  — opt out (alias)
HELP         — receive program help message

Note: SiteWeave does not use START for re-subscribe. After STOP, the recipient must complete web consent or receive a new opt-in text and reply YES again.
